# SalaryThief

薪水小偷（xīnshuǐ xiǎotōu）

## Meaning / 意思

**薪水小偷** is a workplace slang term for an employee who slacks off, loafs, or does personal things on the clock, contributes little productivity, and still collects a full salary.

This Chinese phrase is a calque of Japanese **給料泥棒** (*kyūryō dorobō*), literally “salary thief.”

在工作場合偷懶、擺爛或做私事，沒有貢獻生產力，卻仍然領取薪水的人。詞源於日語「給料泥棒」。
