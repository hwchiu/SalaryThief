1. Put this handoff package into the SalaryThief repository root.
2. Create/checkout a feature branch:
   git checkout -b codex/v2-phase1
3. Run:
   chmod +x BOOTSTRAP-CODEX.sh
   ./BOOTSTRAP-CODEX.sh
4. Start Codex from the repository root.
5. Paste the prompt from START-CODEX.md.
6. Let Codex continue until Phase 1 Definition of Done passes or it reports a concrete stop-condition blocker.
7. Ask:
   "Show the completed acceptance evidence table and summarize every remaining limitation."
8. Review git diff, then commit/push if satisfied.
